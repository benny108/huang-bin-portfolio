## Constraint

A generic Skill Template can describe capabilities but not a company-specific context, process, or strategy. Rewriting Skills per customer increases maintenance cost and inconsistency.

## My actions

- Contributed to Profile generation that extracts scenarios, process summaries, and execution strategies from natural language.
- Generated structured Markdown Profiles that are readable, reviewable, and versionable.
- Contributed to runtime interpretation where a Profile overrides generic Template defaults during planning.

## Value

The approach moves user-specific requirements from disposable prompts into a maintainable configuration layer for reusable enterprise Agent Skills.
